## How signing works

A GitHub bot in the project's repository (CLA Assistant Lite) asks for and records signatures.

1. You open your first pull request.
2. The bot comments on it, with a link to this agreement.
3. If you agree, reply to the pull request with this sentence, exactly as written:
   `I have read the CLA Document and I hereby sign the CLA`
   Posting that sentence is your signature: you agree to this agreement in your own name.
4. The bot records your GitHub username and account number, the link to your comment, the pull request and the time,
   in a file on the repository's `cla-signatures` branch. That record is the evidence that you signed. The pull request's check turns green.
5. You do not sign again for later pull requests, unless this text changes in a way that needs a new signature.

A pull request is not merged until its author has signed.
