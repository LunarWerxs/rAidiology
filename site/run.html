Install the app For researchers

Install the app

Chrome, Edge, Safari and Firefox install it from the address bar or a menu. There is no installer to download.

  • Chrome and Edge

    Windows, Mac, Linux and Chromebook

    Your browser

    The install icon at the right of the address bar.

  • Safari

    Mac

    Your browser

    File › Add to Dock

  • iPhone and iPad

    Safari

    Your device

    Share › Add to Home Screen

    A phone cannot read a disc, so open the ZIP from your patient portal.

  • Android

    Chrome, Edge or Firefox

    Your device

    Menu › Install app

    A phone cannot read a disc, so open the ZIP from your patient portal.

  • Firefox

    Windows, version 143 or newer (150 or newer from the Microsoft Store)

    Your browser

    The web apps button in the address bar. Firefox adds the app to your taskbar and Start menu.

    On other systems Firefox opens it in a tab; Chrome, Edge or Safari can install it as an app.

Once it is installed

  • Its own window

    It opens from your taskbar, Dock or home screen, apart from your browser tabs.

  • Works offline

    After the first visit it needs no internet. Turn off Wi-Fi and it still opens a scan.

  • No account, no updates to run

    Nothing to sign up for. A new version takes over by itself the next time you open it.

For researchers

Run it from the code

The launcher serves the site on 127.0.0.1 and lists the research models. It needs Git and Python 3.9 or newer, and nothing else to install.

Model cards on GitHub Research results

  1. Clone the repository

    git clone https://github.com/LunarWerxs/rAidiology.git

  2. Go to its root

    cd rAidiology

  3. Start the launcher

    python reading/local/launcher.py
