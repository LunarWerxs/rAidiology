Run it on your own computer

Three steps. The browser then opens the app on your own computer; no account and no install.

The steps

  1. 1

    Download the ZIP

    Download the project as a ZIP from GitHub.

  2. 2

    Unzip it

    Right-click the ZIP and choose Extract all (Windows) or double-click it (Mac).

  3. 3

    Double-click the start file

    • Windows: start-windows.bat
    • Mac: start-mac.command. The first time, right-click it and choose Open.
    • Linux: start-linux.sh

    If a Mac or Linux computer will not open the file, open a terminal in the unzipped folder and type bash start-mac.command or bash start-linux.sh.

    A black window opens and your browser opens the app on your own computer.

What you get

The scan opener and the sample scan, working offline. Nothing leaves the computer.

If it says Python is missing

  • Windows: the launcher offers to install it. Or get Python from python.org.
  • Mac: it may ask to install the developer tools; say yes. Or get Python from python.org.

How to stop it

Press the Stop button in the app, or close the black window (Ctrl+C also works).

The research models

The weights are not in the download yet. Each will be a gated download on Hugging Face, saved into the models folder.
