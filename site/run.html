Run it on your own computer

Install it once from your browser. It then works offline; no account.

Install the app

  • Chrome and Edge on Windows, Mac, Linux and Chromebook: use the button above, or the install icon in the address bar.
  • Safari on a Mac: File > Add to Dock.
  • iPhone and iPad: Share > Add to Home Screen. Then open the ZIP from the patient portal, since a phone cannot read a disc.
  • Android: menu > Install app.
  • Firefox on Windows (version 143 or newer; 150 or newer if Firefox came from the Microsoft Store): use the web apps button that appears in the address bar. Firefox then adds the app to your taskbar and Start menu. On other systems Firefox can use the site in a tab, and Chrome, Edge or Safari can install it as an app.

After the first visit it works with no internet. To check, turn off Wi-Fi and open a scan.

For researchers

Clone the repository, then run the launcher from its root. It serves the site on 127.0.0.1 and lists the research models.

git clone https://github.com/LunarWerxs/rAidiology.git
cd rAidiology
python reading/local/launcher.py

The model cards and readers are on GitHub. The weights are not released yet. See the research results.

Not a medical device. For education and research.
